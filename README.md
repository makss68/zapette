# Zapette

Free IPTV player for **Android TV, Google TV, Android phones and tablets**, and the web.

**Zapette is a player only: it includes no channels, films or series.** You sign in with the
Xtream Codes details (server address, username, password) of the subscription you already have from
your provider. Only watch services and content you have the right to watch.

## Download

- **Website:** [zapette.app](https://zapette.app): features, pricing, install guide.
- **Latest APK:** [Zapette.apk](https://github.com/makss68/zapette/releases/latest/download/Zapette.apk)
  (Android 7.0 or later). All versions are under [Releases](https://github.com/makss68/zapette/releases).
- **Web app:** [web.zapette.app](https://web.zapette.app), nothing to install.

On Android TV, install the free **Downloader** app, type `zapette.app/apk`, then allow Downloader to
install apps when Android asks. Each release lists the SHA-256 of its APK.

## Help

Something doesn't work? [Open an issue](https://github.com/makss68/zapette/issues/new) with your device,
the Zapette version (in the release name) and what you did. Never post your server address, username
or password.

This repository hosts the releases and the issue tracker; the source code is not public.
